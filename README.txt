بازی تست چندروزه

ساختار:
- index.html: بازی
- server.js: سرور و ذخیره اطلاعات
- package.json: اجرای Node.js
- images/: تصاویر بازی را اینجا قرار بده
- data.json: خودکار ساخته می‌شود و نباید وارد GitHub شود

برای اجرای محلی:
npm install
npm start
سپس مرورگر: http://localhost:3000

برای تست Render:
Build Command: npm install
Start Command: npm start

نکته: این نسخه برای تست کوتاه‌مدت ساخته شده و ذخیره‌سازی آن فایل‌محور است.
